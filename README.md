METRO ACCESIBILITY ANALYSIS USING GIS

ABSTRACT
This project presents a comprehensive Geographic Information System (GIS)-based analysis of metro accessibility for colleges in Hyderabad, India. The study integrates spatial techniques such as buffer analysis, distance computation, and travel time estimation to evaluate accessibility levels. Locations are classified into High, Medium, and Low accessibility categories, and disparities between central and peripheral regions are examined. The analysis further identifies last-mile connectivity challenges and provides data-driven insights for improving urban transportation planning.

 OBJECTIVES
- To evaluate metro accessibility for educational institutions using GIS  
- To compute distance and travel time to the nearest metro stations  
- To classify accessibility into High, Medium, and Low categories  
- To identify and analyze last-mile connectivity issues  
- To compare accessibility patterns between central and peripheral regions  

 TOOLS & TECHNOLOGIES
- QGIS – Spatial data analysis and visualization  
- OpenStreetMap (OSM) – Base map and spatial data source  
- Microsoft Excel – Data processing and chart generation  


METHODOLOGY
The project follows a structured GIS-based analytical approach:

1. Collection of spatial data from OpenStreetMap  
2. Creation of layers for metro stations, colleges, and road networks  
3. Generation of buffer zones (500m and 1000m) around metro stations  
4. Calculation of distance from colleges to nearest metro stations  
5. Estimation of walking time based on distance  
6. Assignment of accessibility scores and classification levels  
7. Categorization of regions into Central and Peripheral  
8. Identification of last-mile connectivity issues  
9. Visualization using maps and statistical charts  

 ANALYSIS PERFORMED
- Buffer Analysis (500m and 1000m)  
- Distance Measurement  
- Travel Time Estimation  
- Accessibility Scoring and Classification  
- Regional (Central vs Peripheral) Comparison  
- Last-Mile Connectivity Assessment  
- Google Maps vs Calculated Time Validation
